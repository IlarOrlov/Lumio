## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Orphaned headless browsers | Killing only the main Brave PID left 83 renderer processes spinning (load avg 64) | blocking | `shot.js` spawns detached and kills the whole process group (`process.kill(-pid)`); after tests check `pgrep -x brave` count |
| Broad pkill | Killing by pattern can hit the agent's own shell or the live service | blocking | Kill only PIDs whose `/proc/<pid>/environ` contains the preview config path |
| Strict-mode block functions | Wrapping code in `try {}` put function declarations inside a block (SyntaxError in ES5 engines) | blocking | Wrap startup as `function start(){…} try { start() } catch…` |
| Grid on `<button>` | Old engines ignore `display:grid` on buttons → icons off-centre | advisory | Use inline-flex + `svg {display:block}` |
| `Referrer-Policy: no-referrer` | Form navigations send `Origin: null` → CSRF check refused sign-in | advisory | Policy is `same-origin`; `null` accepted only with `Sec-Fetch-Site: same-origin` |
| Unix socket path length | Preview dataDir under the scratchpad exceeded 108 chars | advisory | Use a short dataDir (e.g. `/tmp/claude-1000/lp`) for preview instances, delete after |
| sudo | Agent can't sudo interactively | advisory | Use `pkexec` (graphical prompt) after telling the user a password window will appear |
