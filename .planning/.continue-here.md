## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Parallel encodes by core count | 4 workers x ~3.8 GB RSS triggered OOM kills (more cores ≠ more RAM) | blocking | Size worker count by RAM: floor((available RAM − 3 GB) / 3.8 GB) |
| Orphaned job claims | A killed worker's `claim/<n>` dir made all other workers skip that episode | blocking | After any worker death, remove its claim dir and partial tmp file |
| Leaking test temp dirs | Tests used mkdtemp without cleanup (~80 dirs in /tmp) | advisory | Use `test/tmp.js` (`mkTmp`), which removes folders on exit |
| Broad pkill | Pattern kills can hit the agent's own shell or the live service | advisory | Kill specific PIDs only |
